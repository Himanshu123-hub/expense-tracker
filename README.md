# 💰 Expense Tracker

## 📌 Project Overview

The **Expense Tracker** is a simple and interactive web application developed using HTML, CSS, and Vanilla JavaScript. This project helps users manage their daily income and expenses while keeping track of their available balance.

Users can add new income and expense transactions, view their transaction history, filter transactions, and delete unwanted records. The application automatically calculates total income, total expenses, and the remaining balance.

This project focuses on JavaScript DOM manipulation and demonstrates how to create dynamic web applications without using any JavaScript frameworks.

## ✨ Features

- 💰 Add Income Transactions
- 💸 Add Expense Transactions
- 📊 Automatically Calculate Total Balance
- 🟢 Display Total Income
- 🔴 Display Total Expenses
- 📝 Dynamic Transaction History
- 🔍 Filter Transactions (All, Income, Expense)
- 🗑️ Delete Individual Transactions
- 💾 Save Data Using LocalStorage
- 📱 Responsive User Interface
- 🎨 Modern Dark Theme Design

## 🛠️ Technologies Used

- **HTML5** – To create the structure of the application.
- **CSS3** – To design the user interface and make it responsive.
- **JavaScript (ES6)** – To implement application functionality and calculations.
- **DOM Manipulation** – To dynamically create, update, and remove HTML elements.
- **LocalStorage** – To store transaction data in the browser.

## ⚙️ How It Works

1. Users enter a transaction description and amount.
2. They select the transaction type (Income or Expense).
3. They choose a transaction category.
4. JavaScript dynamically creates a transaction card.
5. The application automatically updates income, expenses, and total balance.
6. Users can filter transactions based on their type.
7. Users can delete individual transactions.
8. All transaction data is saved in LocalStorage, so it remains available after refreshing the browser.
